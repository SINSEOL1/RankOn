# 랭크온 (RankOn)

이터널 리턴 방송용 랭크 오버레이 프로그램입니다.

## 주요 기능

- OBS Browser Source용 방송 오버레이
- Windows PC 오버레이
- 현재 티어, RP, 순위, 시즌 종료까지 남은 기간 표시
- 세션 RP 변화량 표시 및 시작 RP 직접 지정
- 60초 자동 랭크 갱신 및 수동 새로고침
- 데미갓 / 이터니티 상위권 컷 반영
- Light / Dark 테마
- 한국어 / English / 日本語 / 简体中文 지원

## 안내

랭크온은 이터널 리턴 비공식 프로그램입니다.
