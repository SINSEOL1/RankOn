# 랭크온 (RankOn) v1.0.0

이터널 리턴 방송용/데스크톱 랭크 오버레이 프로그램입니다.

## 기능

- 닉네임 등록 및 현재 시즌 랭크 자동 조회
- RP, 전체 순위, 티어, 시즌 종료 시간 표시
- 60초 자동 갱신 및 10초 수동 새로고침 쿨다운
- 세션 RP 변화량, 새 세션, 시작 RP 직접 입력
- 다음 티어 / 데미갓 / 이터니티 목표 RP 표시
- OBS Browser Source 독립 출력
- Windows PC 오버레이 독립 출력
- 위치 이동, 크기, 투명도, 항상 위, 클릭 통과, 잠금
- Ctrl + Shift + R PC 오버레이 표시/숨기기
- Standard / Compact / Minimal / Vertical / Stream Bar 프리셋
- 표시 항목, 배경 투명도, 모서리, 크기 설정
- Light / Dark / 시스템 테마
- 트레이 실행, Windows 시작 시 실행
- GitHub Release 업데이트 확인
- Inno Setup 설치 프로그램

OBS 주소 기본값: `http://127.0.0.1:19872/overlay`

OBS 권장 브라우저 소스 크기: `1200 × 720`

랭크 티어 이미지는 릴리즈 빌드에 포함되며, 네트워크 다운로드는 예비 경로로만 사용합니다.

랭크온은 이터널 리턴 비공식 프로그램입니다.
